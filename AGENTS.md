# Repository Guidelines

## Build, Test, and Development Commands
Use the Makefile for the normal workflow and Go commands for focused checks.

- `make all`
- `make test`
- `make lint`
- `make fix`

## Key Conventions

* Go 1.26+: Use modern golang 1.26+ features. To check use use-modern-go skill
* Commits:  Never commit superpowers plans. Use concise one-line, imperative commit messages such as `add consumer fetch defaults`.
